# Packs & Achievements Specification

This document details the bundle layout, manifest schema, runtime profiles, and achievement definitions for `.onehundo` packs.

---

## 1. Archive Structure

A `.onehundo` archive is an uncompressed or deflate-compressed ZIP archive containing:

```text
package.onehundo
├── manifest.json
├── achievements/
│   ├── main.json
│   └── dlc.json
├── rules/
│   └── custom_eval.wasm       (Optional WASM sandbox logic)
└── assets/
    └── icons/
        ├── ach_001.png
        └── ach_002.png
```

---

## 2. Manifest Schema (`manifest.json`)

The manifest identifies the game release, supported runtime profiles, matchers, and metadata:

### Key Sections:
- **`manifest_version`**: Must be `"0.1.0"` for the provisional release.
- **`canonical_game_id`**: Universal identifier (e.g., `"sony.bloodborne"`, `"nintendo.snes.smw"`).
- **`matchers`**: Multiple identity matchers allowing matching across ROMs, native builds, and releases:
  - `rom_hash`: SHA-256 or MD5 hash of ROM file (Plane A).
  - `recomp_game_id`: Identifier used by static recompilation runtimes.
  - `build_id`: Executable build fingerprint or git commit hash (Plane B).
  - `platform_id`: Platform app ID (e.g., Steam AppID, GOG product ID).
  - `sidecar_uuid`: Explicit UUID embedded into game configs or mods.
  - `asset_archive_hash`: SHA-256 hash of core game archive files.
- **`profiles`**: Array of runtime profiles supported by this pack:
  - `memory`: Memory arena configuration, region definitions, memory offsets.
  - `semantic`: Semantic event schemas, stat definitions, target thresholds.
  - `observation`: Save file scan paths, format parser rules.
- **`achievements`**: Summary list of achievement IDs, titles, descriptions, and point values.
- **`signatures`**: Cryptographic signatures generated by OneHundo platform or verified pack authors.

---

## 3. Achievement Definition Structure

Each achievement entry includes:
- **`id`**: Unique alphanumeric identifier within the pack (e.g., `"defeat_cleric_beast"`).
- **`title`**: Human-readable name.
- **`description`**: Objective description.
- **`points`**: Gamerscore points (e.g. 5, 10, 25, 50, 100).
- **`progression_mode`**: Target mode (`STANDARD`, `ENCORE`, `SPECTATOR`).
- **`trust_tier`**: Required trust tier (`LOCAL`, `VERIFIED_INTEGRATION`, `COMPETITIVE`).
- **`trigger`**: Trigger conditions:
  - For Plane A: Memory addresses, comparison operators, hit counts, resets.
  - For Plane B: Semantic event predicates (e.g., `event == "STAT_INC" && stat == "bosses_killed" && value >= 1`).
  - For Plane C: Save file JSONPath or binary byte offset comparisons.
